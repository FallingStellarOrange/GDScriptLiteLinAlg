## Project Overview

**GDScriptLiteLinAlg**, Chinese name **GDScript轻量线代工具**, abbreviated as **GDSLLA**, is independently developed by _坠入·Stellar Orange_ in GDScript. A lightweight matrix linear algebra computation plugin for GDScript, designed for small-scale use.

### ./addons/gdscript_lite_linalg - Matrix Type

**Created**: 2026-11-27

#### Matrix.gd

1. **Created**: 2026-11-27
2. **Modified**: 2026-11-27
3. **Location**: [addons/gdscript_lite_linalg/Matrix.gd](../../addons/gdscript_lite_linalg/Matrix.gd)
4. **Overview**: Defines the `LiteMatrix` lightweight matrix type, designed for small-scale dense real matrices
5. **Logic**:
    - Defines the `LiteMatrix` class, extending `RefCounted`
    - Describes the matrix with three members: `rows`, `cols`, and `data`
    - Provides basic operations: `from_array`, `get_value`, `set_value`, `clone`, `transpose`
    - Provides the `CommonSquareMatrices` enum and a unified `structure_square` construction entry
    - Provides three convenience constructors: `identity`, `zeros`, `ones`
6. **References**: None
7. **Global Variables**: None
8. **Functions**: None (all are class methods)
9. **Classes**:
    - **LiteMatrix**:
        1. **Overview**: Lightweight matrix type, designed for small-scale dense real matrices
        2. **Variables**:
            - **rows** (_int_): Number of rows
            - **cols** (_int_): Number of columns
            - **data** (_PackedFloat64Array_): Matrix data stored in a one-dimensional array, index = `row * cols + col`
        3. **Enums**:
            - **CommonSquareMatrices**: Common square matrix types, including `ZEROS` (zero matrix), `IDENTITY` (identity matrix), `ONES` (all-ones matrix)
        4. **Methods**:
            - **_init**: Constructor, creates a zero matrix with the given rows and columns
            - **from_array** (_static_): Converts a 2D `Array` to `LiteMatrix`
            - **get_value**: Gets the data at `(r, c)`
            - **set_value**: Sets the data at `(r, c)`
            - **clone**: Clones the matrix into a new matrix
            - **transpose**: Returns the transpose of the current matrix
            - **structure_square** (_static_): Constructs a common square matrix by enum
            - **identity** (_static_): Constructs an identity matrix
            - **zeros** (_static_): Constructs a zero matrix
            - **ones** (_static_): Constructs an all-ones matrix
